SEO & DISCOVERABILITY
---------------------

[ ] robots.txt configured
    - /robots.txt or public/robots.txt allows search engines
    - Points to sitemap location
    Verify: curl https://example.com/robots.txt returns valid robots directives

[ ] Sitemap generated
    - Sitemap available at /sitemap.xml or /sitemap-index.xml
    - All public pages included
    Verify: curl https://example.com/sitemap.xml returns valid XML sitemap

[ ] LocalBusiness structured data (JSON-LD)

[ ] Canonical link tag
